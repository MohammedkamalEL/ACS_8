# ساعدني | SOS

واجهة ويب تجريبية تساعد الشخص وقت الطوارئ على الوصول إلى الجهة المناسبة بأقل عدد من الخطوات.

الفكرة: من الصفحة الرئيسية يضغط المستخدم زر **SOS** أو يختار نوع الطوارئ، فيظهر له مباشرة الإرشاد المختصر وأرقام الجهات المناسبة مع زر اتصال مباشر.

> الأرقام في هذه النسخة وهمية (`000-000-00X`) ولا تعمل كأرقام طوارئ فعلية.

## الميزات

- زر SOS كبير في الصفحة الرئيسية يفتح شاشة **الطوارئ الآن** فيها اتصال بالإسعاف والشرطة والإطفاء بضغطة واحدة.
- يعمل التطبيق بدون إنترنت من أول زيارة، بما فيه الخط العربي (Service Worker وملف Manifest، يُفعّلان في نسخة الإنتاج فقط). وتوجد اختصارات على أيقونة التطبيق: الطوارئ الآن، أنا بخير؟، جهاتي.
- **جهات طوارئ شخصية** (حتى 5 أشخاص): تظهر أولاً في شاشة الطوارئ مع اتصال ورسالة نصية جاهزة.
- **البطاقة الطبية:** فصيلة الدم والحساسية والحالات المزمنة والأدوية، تُعرض للمسعفين في شاشة الطوارئ.
- **مشاركة رسالة الطوارئ** تتضمن الموقع المكتوب والبيانات الطبية، مع **معاينة** للنص قبل الإرسال، وتُرسل عبر تطبيقات الهاتف أو تُنسخ.
- **موقع دقيق اختياري:** زر "أضف موقعي الدقيق" يضيف رابط خريطة للرسالة. لا يُطلب الإذن إلا عند الضغط، ولا يُحفظ، وإن رُفض أو تعذّر يبقى الموقع المكتوب بالكلمات.
- **بحث** سريع بين أنواع الطوارئ يتجاهل الهمزات والتشكيل ويفهم كلمات مثل: عقرب، موتر، نار.
- **زر اتصال في أعلى كل نوع:** أهم جهة (مثل الإسعاف) تظهر قبل الإرشادات، فيتصل المستخدم بضغطة واحدة دون تمرير.
- **بطاقة "جهّز نفسك"** في الرئيسية تظهر حتى يضيف المستخدم جهة موثوقة وبطاقته الطبية.
- **مؤقت "أنا بخير؟":** تحدد 15 أو 30 أو 60 دقيقة، وإن انتهى الوقت دون تأكيد تظهر جهات الطوارئ الشخصية والطوارئ الرسمية. المؤقت يبقى بعد إعادة تحميل الصفحة، ويمكن تمديده 15 دقيقة. عند الانتهاء يهتز الجهاز ويظهر **شريط تنبيه في كل الصفحات**، مع رسالة جاهزة لجهة الاتصال. وهو تذكير على الجهاز فقط، ويحتاج بقاء التطبيق مفتوحًا، ولا يُرسل تنبيهًا تلقائيًا لأحد.
- **سجل الطوارئ:** يسجّل الاتصالات والرسائل والمشاركات والمؤقتات على الجهاز، ويمكن مسحه من صفحة "جهاتي".
- **تنبيه انقطاع الإنترنت** يطمئن المستخدم أن الإرشادات وجهات الاتصال متاحة.
- **تثبيت التطبيق** على الشاشة الرئيسية للهاتف عندما يتيحه المتصفح.
- **شريط تنقل سفلي** على الهاتف، وروابط تنقل في الرأس على الحاسوب، وزر SOS دائم في رأس الهاتف.
- **شاشة بديلة عند الأخطاء:** لو تعطلت أي شاشة تظهر أزرار اتصال مباشرة بدل صفحة بيضاء.
- **الخصوصية:** كل البيانات الشخصية تُحفظ على الجهاز فقط (localStorage) ولا تُرسل إلى أي خادم.
- إتاحة محسّنة: رابط تخطٍّ للمحتوى، تركيز واضح لكل عنصر، أزرار بحجم مناسب للمس، وتوقف الحركات لمن يفضّل تقليلها.
- سبعة أنواع طوارئ: حالة صحية، حريق أو تسرب غاز، أمن وشرطة، حادث مروري، لدغة أو تسمم، شخص مفقود، ومساعدة أخرى.
- لكل نوع: إرشادات مختصرة مرقّمة، ثم جهات اتصال.
- زر **اتصل الآن** يفتح الاتصال مباشرة (`tel:`) عند توفر الرقم.
- زر **نسخ الرقم** مع تأكيد بصري.
- عند غياب الرقم تظهر رسالة توجّه المستخدم إلى الإرشاد بدل ترك الشاشة فارغة.
- واجهة عربية كاملة (RTL) وتصميم متجاوب للهاتف أولاً.
- لا تعتمد على خرائط أو GPS أو أنظمة متقدمة؛ الموقع الدقيق ميزة اختيارية فقط.

## المتطلبات

- Node.js 20.19 أو أحدث

## التشغيل

```bash
npm install
npm run dev       # يفتح على http://localhost:5173
npm run build     # بناء الإنتاج في مجلد dist
npm run preview   # معاينة نسخة الإنتاج
npm run lint      # فحص الكود
```

## أين أضيف الكود؟

| تريد أن... | تضيفه في |
|---|---|
| نوع طوارئ جديد أو تغيير رقم | `src/data/emergencyTypes.js` (أضف `keywords` ليسهل البحث) |
| رابط جديد في شريط التنقل | `NAV_ITEMS` في `src/data/options.js` |
| عنصر عرض جديد (زر، بطاقة) | `src/components/` |
| صفحة جديدة | `src/pages/` ثم سجّل مسارها في `src/App.jsx` |
| جلب بيانات من الـ backend | `src/api.js` ثم hook في `src/hooks/` |
| لون أو خط عام | `src/App.css` داخل `@theme` |

## ربط الـ Backend أو الـ Microservice

الكود الحالي يستخدم بيانات محلية في `src/data/emergencyTypes.js` وتُعرض فوراً بلا انتظار. عند الربط:

1. أضف متغير البيئة في ملف `.env.local` (لا ترفعه إلى Git):
   ```
   VITE_API_URL=https://your-gateway.example.com/api
   ```
2. يجلب `src/api.js` من `GET {VITE_API_URL}/emergency-types` مرة واحدة ويحتفظ بالنتيجة، والرد قائمة بنفس شكل `EMERGENCY_TYPES`.
3. إن فشل الخادم أو انقطع الإنترنت (أكثر من 5 ثوانٍ) يرجع التطبيق تلقائياً إلى البيانات المحلية، فلا تبقى الشاشة فارغة وقت الطوارئ.
4. لا تغيّر المكونات ولا الـ hooks، فهي لا تعرف مصدر البيانات.

## ملاحظات على الخصوصية والسلامة

- البيانات الشخصية (الجهات، البطاقة الطبية، السجل، المؤقت) تُحفظ على جهاز المستخدم فقط في `localStorage`، ولا تُرسل إلى أي خادم. الموقع الدقيق لا يُحفظ أصلاً.
- المطلوب في النسخة الأولى هو التجربة والتصميم، وليس دليل أرقام رسمي. يجب استبدال الأرقام بالجهات المعتمدة قبل أي استخدام حقيقي.
